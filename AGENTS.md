
# Правила роботи з проєктом

1. **Початок роботи:** Перед виконанням будь-якого завдання обов'язково прочитай файл `STATUS.md` у корені проєкту, щоб зрозуміти поточний стан справ, архітектуру та вже виконані кроки.
2. **Збереження контексту:** Після завершення кожного значущого етапу роботи або за першою вимогою користувача («Збережи контекст»), онови файл `STATUS.md`.
3. **Формат `STATUS.md`:** Файл має містити 4 короткі розділи:
   - **Мета проєкту:** (1–2 речення про суть задачі).
   - **Що вже зроблено:** (список готових файлів і функцій).
   - **Поточні проблеми / Баги:** (якщо щось не працює).
   - **Наступний крок:** (конкретна дія, з якої треба продовжити роботу).
4. **Мова:** Спілкуйся з користувачем українською мовою.
