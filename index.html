Тестовий комплект №17 · локальний прототип без запису в Google Sheets

1. Робоча ділянка

NFC ще не запущено. Потрібен Android + Chrome і сторінка, відкрита через HTTPS.

Після натискання «Почати» тримайте мітки по черзі біля телефона. Сторінка має залишатися відкритою та активною. Якщо браузер не підтримує Web NFC, перевірте Chrome на Android і дозвіл NFC у телефоні.

2. Комплектність склейки

Для склейки сканується будь-яка одна половинка виробу. Для кіля після сканування потрібно вказати, що саме виготовили. Ліва матриця кіля дозволяє тільки стабілізатор; обидві праві можуть бути стабілізатором або рудером.

5. Підготовка NFC-міток

Кожна мітка має містити NDEF-запис типу URL із адресою цієї сторінки та параметром ?tag=ІДЕНТИФІКАТОР. Наприклад: https://ВАШ-ДОМЕН/?tag=M017-FU-UP. Усі 12 URL мають вести на ту саму сторінку, але мати різний параметр tag.

Для тесту можна спершу запрограмувати 2–3 мітки. Не використовуйте адресу-заглушку: спочатку розмістіть цей файл на HTTPS-хостингу, потім підставте його адресу в NFC Tools.
