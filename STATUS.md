
# STATUS

## Мета проєкту

Розробити систему NFC-ідентифікації матриць для виробництва Farm ERP. Система має фіксувати проходження фізичних половинок матриць через виробничі ділянки, облік склейки виробів та історію використання матриць.

## Що вже зроблено

- Узгоджено структуру одного комплекту: 12 фізичних половинок матриць і 12 NFC-міток.
- Узгоджено ідентифікацію:
  - Фюзеляж — верхня та нижня половинки.
  - Ліве крило — верхня та нижня половинки.
  - Праве крило — верхня та нижня половинки.
  - Лівий кіль — верхня та нижня половинки.
  - Правий кіль №1 — верхня та нижня половинки.
  - Правий кіль №2 — верхня та нижня половинки.
- Визначено чотири ділянки NFC-обліку:
  - Підготовка матриць.
  - Фарбування.
  - Вакуумування.
  - Склейка виробів.
- Для перших трьох ділянок сканування фіксує конкретну фізичну половинку матриці.
- Для склейки достатньо відсканувати будь-яку одну половинку виробу.
- Для крил NFC розрізняє ліве та праве крило.
- Для кіля після сканування працівник обирає результат: стабілізатор №1, стабілізатор №2 або рудер.
- Ліва матриця кіля використовується тільки для стабілізатора.
- Будь-яка з двох правих матриць кіля може використовуватися для стабілізатора або рудера.
- Узгоджено контроль комплектності склейки: 1 фюзеляж, 2 крила, 2 стабілізатори та 1 рудер.
- Узгоджено захист від повторного сканування, виправлення помилок, облік заміни, ремонту та списання матриць зі збереженням історії.
- Узгоджено відображення кількості відсканованих половинок і повністю сформованих комплектів.
- Створено тестовий HTML-прототип для комплекту №17.
- Створено публічний GitHub-репозиторій `makssevv-star/farm-erp-nfc-test`; прототип завантажено як `index.html`.
- Додано `AGENTS.md` і `STATUS.md`.
- У прототипі передбачено вибір ділянки, запуск Web NFC, локальний журнал операцій, контроль склейки, скасування останньої операції та експорт JSON.
- Підготовлено покрокову інструкцію з розміщення прототипу на GitHub Pages.

## Поточні проблеми / Баги

- Безперервне NFC-сканування ще не перевірено на Xiaomi 15 (Android 16).
- Не підтверджено публікацію прототипу на GitHub Pages.
- Прототип не інтегрований із Google Sheets та основним вебзастосунком Farm ERP.
- Реальний облік заміни, ремонту та списання матриць ще не реалізований.
- Дані прототипу зберігаються локально в браузері, а не в робочому журналі ERP.
- Потрібно перевірити роботу Web NFC та коректність зчитування всіх 12 міток.

## Наступний крок

Перевірити або ввімкнути GitHub Pages для `index.html`, потім перевірити на Xiaomi 15 безперервне зчитування кількох NFC-міток поспіль без повторного відкриття сторінки. За результатами тестування визначити технічний спосіб інтеграції NFC у Farm ERP.
